Guardá aquí las seis fotos personales con estos nombres sugeridos: `mama-01.jpg` a `mama-06.jpg`. También se aceptan PNG o WebP. Una imagen de al menos 1200 px en el lado más largo suele verse muy bien; comprimila antes de publicar para que la página cargue rápido.

Para activar una foto, añadila aquí y cambiá el `imageSrc` correspondiente de `null` a, por ejemplo, `"/photos/mama-01.jpg"` en `src/data/content.ts`. Actualizá también `imageAlt` con una descripción real y útil de esa foto. Mientras `imageSrc` sea `null`, la galería muestra un placeholder y no intentará cargar ninguna ruta inexistente.

Para la foto final actual, usá `mama-final.jpeg`; si cambiás formato o nombre, actualizá `final.photo.imageSrc` y escribí un `imageAlt` descriptivo. Si hace falta, ajustá `objectPosition` en el mismo objeto para encuadrar mejor los rostros.
