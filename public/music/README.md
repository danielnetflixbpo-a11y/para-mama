# Música

Podés agregar opcionalmente `mama.mp3` aquí. MP3, M4A y OGG son formatos recomendados; comprimí el archivo antes de publicar y usá únicamente música para la que tengas permiso.

Para activarla, configurá `final.music.src` como `"/music/mama.mp3"` en `src/data/content.ts`. El reproductor nunca inicia solo: los navegadores requieren una acción de la persona para reproducir audio.
